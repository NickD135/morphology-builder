# SVG Hair — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A Hair cosmetic system — hairstyles + hair-colour palette — rendered as soft-shaded SVG on the character, layered correctly (over the shaded scalp, under hats), with a new shop Hair + Hair Colour category. No geometry change to the head or any accessory.

**Architecture:** New `hairSVG` map in `buildSVG` rendered in a specific draw order (long styles behind the head, main hair over the shaded scalp under the face/accessories); `hair`+`hairColor` scientist fields (no DB migration); two new shop categories mirroring the existing skin (swatch) + heads (mini-preview) machinery.

**Tech Stack:** Vanilla JS, inline SVG, `_mix` helper (already in `buildSVG`), Playwright + no-cache server.

**Spec:** `docs/superpowers/specs/2026-07-01-svg-hair-design.md`

## Global Constraints
- Vanilla JS, no build, no new deps, **no DB migration** (`hair`/`hairColor` are new keys on the existing `scientist` jsonb; `save_scientist_field` accepts them like `world`).
- **Frozen anchors:** head stays `cx40 cy38 r22`; no existing shape/accessory coordinate changes. Hair is authored relative to the head.
- **Default `hair=null` = today's bare head** (existing characters unchanged). Default `hairColor='#3B2A1E'`.
- **Draw order (D3):** [behind-head long-hair layer] → head fill → head shade/highlight overlays → **main hair** → face → head accessory. Hats/head accessories render OVER hair. Hair never covers the eyes (`cx34/46 cy36`) or mouth.
- **Per-instance uid** on hair gradient ids. No `<filter>`, no motion (static, low-stim safe). Legible at 44px (bold silhouettes, not fine strands).
- Reactions, existing accessories, coats, and the base shading all still compose.
- Verification = synthetic harness (no login). Merge **local, not pushed**.
- Aesthetic choices are conservative defaults — the sweep produces screenshots + a checklist for the owner's review.

## Style id list (v1 — both the renderer and the shop must use these exact ids)
`none` (free, bald default), `short`, `tousled`, `side_part`, `bob`, `curly`, `afro`, `spiky`, `mohawk`, `ponytail`, `bun`, `long`.
(`ponytail`, `long`, `bun` have a **behind-head** sub-layer; the rest are front/scalp only.)

## Hair colour palette (exact ids/hexes — shop + previews)
Black `#1A1A1A`, Dark Brown `#3B2A1E`, Brown `#6F4E37`, Chestnut `#8D5A3C`, Auburn `#8C3B2B`, Ginger `#C1502E`, Blonde `#D9B36A`, Platinum `#E8DCC0`, Grey `#9A9A9A`, Blue `#3B82F6`, Pink `#F472B6`, Violet `#A855F7`, Mint `#5FC9A6`.

## Task 1: Hair renderer in buildSVG
**Files:** Modify `wordlab-scientist.js`. Create `tests/manual/svg-hair-harness.html`.

- [ ] **Step 1:** In `buildSVG`, read `const hair = scientist.hair || null;` and `const hairColor = scientist.hairColor || '#3B2A1E';`. Derive `const hairHi = _mix(hairColor,'#FFFFFF',0.30);` and `const hairLo = _mix(hairColor,'#000000',0.30);`. Build a uid-suffixed hair gradient `hairG${uid}` (radial or linear: `hairHi` top → `hairColor` → `hairLo` bottom, `stop-color`+`stop-opacity`).
- [ ] **Step 2:** Author a `hairSVG` object with all 12 style ids (list above). Each value is an inline SVG string shaped to the head (hairline ~`cy18-30`, sides to ~`cy40`), filled with `url(#hairG${uid})` (or `hairColor` for flat styles), NEVER covering `cy>32` at the eye centres. Keep bold, readable silhouettes. `none` = `''`. Author them tastefully:
  - `short`: a rounded cap over the top/sides of the head.
  - `tousled`: short cap with a few soft peaks on top.
  - `side_part`: cap with an off-centre parting sweep.
  - `bob`: cap + chin-length sides framing the face (sides to ~`cy52`, OUTSIDE the head edge, not over the face).
  - `curly`: cap made of overlapping small circles (bumpy outline).
  - `afro`: a large rounded cloud around/above the head (bold circle silhouette).
  - `spiky`: cap with several triangular spikes on top.
  - `mohawk`: a central raised strip of spikes, sides shaved (thin sideburn hint).
  - `ponytail`: cap + a **behind-head** tail sub-shape to one side/back (down to ~`cy70`).
  - `bun`: cap + a small round bun above/behind the crown.
  - `long`: cap + a **behind-head** curtain of hair down past the shoulders (~`cy75`, behind the head+coat sides).
  For styles with a behind-head part, emit it from a **separate** `hairBackSVG[id]` string (see Step 3).
- [ ] **Step 3:** Add `const hairBackSVG = { ponytail:'…', long:'…', bun:'…' };` (behind-head sub-shapes) and `const hairFront = hair && hairSVG[hair] ? hairSVG[hair] : '';` and `const hairBack = hair && hairBackSVG[hair] ? hairBackSVG[hair] : '';`.
