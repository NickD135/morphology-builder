# Unit 22 — Stage 0 Draft Rubric

**Unit:** Mathematics Stage 3 **Year B** — Unit 22
**Topic:** **Addition & Subtraction Strategies and Decimals** — efficient mental/written strategies for
addition and subtraction; multistep word problems; estimation, rounding and place-value error checking;
extending place value beyond hundredths (thousandths as decimals, partitioning decimals, decimals on a
number line, approximating); and adding and subtracting decimals to 3 dp through modelling, word problems
and justifying the strategy.
**Source:** `DoE Unit 22.zip` → `Mathematics-Stage3-Unit22.docx`, 8 lessons.
**Year note:** **Year B** unit (the "Year A" strings are prior-learning cross-references).
**Strands / outcomes (from the SC tables + the "Outcomes and content" grid, Table 27):**
- `MA3-AR-01` — *selects and applies appropriate strategies to solve addition and subtraction problems* — content groups **A** (estimation, place-value checking, add 3+ numbers) and **B** (efficient strategies, multistep, decimal word problems, justify)
- `MA3-RN-01` — *applies an understanding of place value… to represent the properties of numbers* — content group **A** (thousandths, partitioning decimals)
- `MA3-RN-02` — *compares and orders decimals up to 3 decimal places* — content group **A** (number line, approximate)
- `MAO-WM-01` — Working mathematically (throughout)

> **Banding — cognitive demand (per `feedback_solo_band_a_heavy_units`, set by Nick 2026-06-20).** Unit 22 is
> an early Year B unit (gradual release) with a real A/B mix but still A-heavy. Banded by **SOLO cognitive
> demand**: recall/single-step/foundational → **Red**; applying/multi-step/reasoning → **Yellow** — across
> both A and B content. The A/B group label is recorded on every content point. Green = Stage 4 **Core**.

## 0a. Flat pool of extracted success criteria ("Students can …")

1. solve problems that require more than one operation (multistep) *(AR-B; L1)*
2. compare and explain strategies for solving addition/subtraction problems *(AR-B; L4)*
3. round numbers appropriately to estimate solutions *(AR-A; L2)*
4. use place value understanding to check for errors in calculations *(AR-A; L2)*
5. use place value to add 3 or more numbers with different numbers of digits *(AR-A; L3)*
6. express thousandths as decimals; interpret decimal notation using place value *(RN-A; L5)*
7. indicate the place value of digits in decimals to 3 dp; partition decimals using place value *(RN-A; L5)*
8. place decimal numbers of up to 3 decimal places on a number line *(RN-A; L5)*
9. approximate the size of decimals *(RN-A; L5, L8)*
10. model the addition of decimals up to 3 decimal places *(AR-B; L6)*
11. model the subtraction of decimals up to 3 decimal places *(AR-B; L7)*
12. solve word problems involving the addition and subtraction of decimals up to 3 dp *(AR-B; L8)*
13. justify why the chosen strategy is effective *(AR-B; L8)*

## 0b–0c. Classified, banded rubric

### 🔴 RED — recall / single-step / foundational

**R1 — Decimal place value to thousandths**
*"I can express thousandths as decimals, read the place value of each digit to 3 decimal places, and partition decimals using place value."*
Band: **Red** · **[written/digital-appropriate]** *(place value chart)*
Covers SC 6, 7. *Represents numbers **A** (`MA3-RN-01`). Content points: "Express thousandths as decimals"; "Interpret decimal notation for thousandths"; "Indicate the place value of digits in decimal numbers of up to 3 decimal places"; "Use place value to partition decimals."*

**R2 — Place decimals on a number line and approximate**
*"I can place decimals to 3 decimal places on a number line and approximate a decimal's size."*
Band: **Red** · **[hands-on-preferred]** *(decimal number line)*
Covers SC 8, 9. *Represents numbers **A** (`MA3-RN-02`). Content points: "Place decimal numbers of up to 3 decimal places on a number line"; "Approximate the size of decimals."*

**R3 — Round to estimate and check calculations**
*"I can round numbers to estimate an answer and use place value to check a calculation for errors."*
Band: **Red** · **[written/digital-appropriate]**
Covers SC 3, 4. *Additive relations **A** (`MA3-AR-01`). Content points: "Round numbers appropriately when obtaining estimates to numerical calculations"; "Use place value understanding to check for errors in calculations."*

**R4 — Add three or more numbers using place value**
*"I can use place value to add 3 or more numbers that have different numbers of digits."*
Band: **Red** · **[written/digital-appropriate]**
Covers SC 5. *Additive relations **A** (`MA3-AR-01`). Content point: "Use place value to add or subtract 3 or more numbers with different numbers of digits."*

### 🟡 YELLOW — applying / multi-step / reasoning

**Y1 — Choose, compare and explain efficient strategies**
*"I can choose an efficient strategy for an addition or subtraction problem, and compare and explain which strategy works best."*
Band: **Yellow** · **[written/digital-appropriate]**
Covers SC 2. *Additive relations **B** (`MA3-AR-01`). Content points: "Choose and use efficient strategies to solve addition and subtraction problems"; "Compare, evaluate and communicate strategies used to solve addition and subtraction problems."*

**Y2 — Solve multistep word problems**
*"I can solve a word problem that needs more than one operation."*
Band: **Yellow** · **[written/digital-appropriate]**
Covers SC 1. *Additive relations **B** (`MA3-AR-01`). Content point: "Solve multistep word problems, including problems that require more than one operation."*

**Y3 — Add and subtract decimals**
*"I can model and calculate the addition and subtraction of decimals up to 3 decimal places."*
Band: **Yellow** · **[hands-on-preferred]** *(place value chart)*
Covers SC 10, 11. *Additive relations **B** (`MA3-AR-01`). Content point: "Model the addition and subtraction of decimals up to 3 decimal places using appropriate representations."*

**Y4 — Solve decimal word problems and justify the strategy**
*"I can solve word problems by adding and subtracting decimals to 3 dp, and justify why my strategy is effective."*
Band: **Yellow** · **[written/digital-appropriate]**
Covers SC 12, 13. *Additive relations **B** (`MA3-AR-01`). Content points: "Solve word problems involving the addition and subtraction of decimals up to 3 decimal places"; "Justify why the strategy used to solve addition and subtraction word problems is appropriate."*
